# 🌦️ Weather App

A simple and responsive weather application built using **HTML, CSS, and JavaScript**. It uses the OpenWeatherMap API to fetch real-time weather information for cities around the world.

## ✨ Features

- 🌍 Search for weather by city name
- 🌡️ Display current temperature in Celsius
- ☁️ Show weather conditions with an icon and description
- 🥵 Display the feels-like temperature
- 💧 Show humidity levels
- 💨 Display wind speed
- ⌨️ Search using the Enter key
- 🔄 Loading messages while fetching weather data
- ⚠️ Handle invalid city names and API errors
- 📱 Responsive interface for different screen sizes

## 🛠️ Technologies Used

- **HTML5** — Structure of the application
- **CSS3** — Styling and responsive layout
- **JavaScript (ES6+)** — Application logic and API requests
- **OpenWeatherMap API** — Weather data

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/weather-app.git
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Open the project

Navigate to the project folder and open `index.html` in your browser.

For local development, you can also use the Live Server extension in VS Code.

### 3. Configure the API

Get an API key from [OpenWeatherMap](https://openweathermap.org/api).

For a frontend-only project, browser JavaScript cannot keep an API key secret. Use only a key intended for browser use, and configure domain restrictions and usage limits if your provider supports them. Never commit private credentials to GitHub.

### 4. Run the application

Open the website, enter a city name, and click the search button to view its current weather.
